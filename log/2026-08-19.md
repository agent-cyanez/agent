## Session — Merge Gate + Expanded Access (18:33 -04)

- **Built `scripts/merge-gate.sh`:** deterministic self-merge policy enforcement. Inspects branch diffs and returns one of three verdicts:
  - **AUTO_MERGE** — only config, lockfiles, Dockerfiles, docs, CI config, static assets changed
  - **TEST_REQUIRED** — source code changed but no dangerous patterns (migrations, auth, networking); auto-merge allowed if test suite passes

- Review reasons dominate: any PATRON_REVIEW file blocks the entire PR.
